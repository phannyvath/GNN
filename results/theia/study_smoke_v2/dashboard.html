Data and protocol

  • train: 12,288 node occurrences / 17,651 edges; labels {'positive': 0, 'presumed_background': 0, 'unknown': 12288}
  • validation: 4,096 node occurrences / 5,719 edges; labels {'positive': 0, 'presumed_background': 4096, 'unknown': 0}
  • test: 4,096 node occurrences / 5,260 edges; labels {'positive': 56, 'presumed_background': 4040, 'unknown': 0}

All eligible training nodes used; no benign-only filtering. RF fits all training rows using standard bootstrap trees. MAGIC retains all training embeddings with exact multiplicity compression. One complete graph per neural batch within declared node/edge caps.

Training time includes scaling, optimization, epoch validation, checkpoints and reference construction. Test scoring time excludes graph reads and CSV writing. Peak memory is worker OS high-water RSS, not whole-machine memory.
